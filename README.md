## ❓ Frequently Asked Questions (FAQ)

**Q: Do I need an internet connection to use SKmart POS everyday?**  
No! The app works entirely offline. All your data saves locally on your computer. Only download updates and optional cloud backup require internet.

**Q: Can I use this on a tablet or phone?**  
Yes, but this guide focuses on Windows desktop installation. The app also runs on Android tablets/hones via the same repository. For now, follow the Windows steps above.

**Q: I accidentally deleted a product. How do I get it back?**  
Go to “Inventory” → “Deleted Items.” You’ll see a list of removed products. Click “Restore” next to the item you need. 

**Q: How do I update SKmart POS to a newer version?**  
Just download the latest `.exe` file from the same link, run it, and it will replace the old version. Your data remains safe—the installer keeps your existing database. 

**Q: Is my data backed up automatically?**  
SKmart POS saves a local backup file every day. You can also manually export a backup using “Settings” → “Backup & Restore” → “Create Backup.” Save that file to a USB drive or cloud folder for extra safety. 

## 🛠️ Troubleshooting Tips

- **App won’t open?** Make sure you double-clicked the `.exe` installer and completed the setup. Try right-clicking the desktop icon → “Run as administrator” once. 
- **Barcode scanner not working?** Plug in the scanner, then open Settings → Hardware → select “USB Scanner” mode. Test in any text field—if the cursor types numbers, it’s ready. 
- **Can’t see the “Reports” tab?** The Reports feature unlocks after you make your first sale. Complete any sale via the POS screen, then refresh the Reports page.
