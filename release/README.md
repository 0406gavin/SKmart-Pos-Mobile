# Release Binaries Directory (Android APKs) – SKmart POS

This directory documents compiled distributables and APK artifacts generated by Capacitor and Gradle build scripts.

### Generating Debug APK:
```bash
npm run build:apk
```
The compiled Android Debug APK file (`app-debug.apk`) will be created in:
`android/app/build/outputs/apk/debug/app-debug.apk`

### Generating Release APK:
```bash
cd android && ./gradlew assembleRelease
```
The release APK (`app-release.apk`) will be generated in:
`android/app/build/outputs/apk/release/app-release.apk`

*Note: Binary `.apk` and `.aab` files are excluded by `.gitignore` to maintain a lightweight source repository.*
